APIs Ativas & Operacionais
O que é e Por Que Usar a API do GPS Paraíba?

Uma **API (Interface de Programação de Aplicações)** é uma ponte digital que permite que outros sistemas (como o seu site de vendas, formulários de WhatsApp, gateways de pagamento ou CRMs externos) conversem diretamente com o ERP da GPS Paraíba sem precisar de intervenção manual.

Verbo GET (Consultar Dados)

Usado para buscar/ler informações salvas no ERP. Exemplo: Seu CRM externo consulta quantas vendas foram realizadas hoje ou quais mensalidades estão pendentes.

Verbo POST (Cadastrar Dados)

Usado para enviar e salvar novos dados no ERP. Exemplo: Quando um cliente preenche um formulário de contratação no site, o site dispara um `POST` e o contrato já aparece pronto no painel.

Autenticação Padrão RFC 6750 (Bearer Token)
1. Bearer Token (Padrão)
Envie o cabeçalho padrão Authorization: Bearer <token> em cada chamada.
2. Formato Padrão JSON
Todas as respostas da API usam a estrutura leve e universal JSON UTF-8.
3. Códigos HTTP
200 OK (sucesso), 201 Created (criado), 400 (dados inválidos) e 401 (sem permissão).

Guia Passo a Passo: Como Testar a API no Postman (Para Devs Júnior)
O que é um Bearer Token? Pense no Bearer Token como o seu crachá VIP digital. A palavra "Bearer" significa "Portador". Quando você faz uma requisição HTTP enviando esse código no cabeçalho (*Header*), a API do GPS Paraíba sabe que é o seu sistema autorizado fazendo a operação.
1
Definir o Método e URL

No Postman, crie uma nova aba, escolha o método POST e cole a URL:
https://gpsparaiba.com.br/api/v1/integracoes/vendas

2
Configurar Autenticação

Clique na aba Auth -> Selecione Type: Bearer Token -> Cole no campo Token a chave:
gps_live_key_paraiba_2026

3
Preencher o Corpo (Body)

Clique na aba Body -> Marque a opção raw -> Mude a chave à direita de Text para JSON e cole o payload de envio.

4
Enviar e Receber 201

Clique no botão azul Send. Você receberá o retorno 201 Created confirmando que o cadastro foi realizado com sucesso no ERP!

Modelo de JSON Copiável para o Body no Postman:

  "contact": "999887766",

Dicionário de Respostas HTTP (Para Entender os Retornos)
Código HTTPSignificadoQuando Acontece?
200 OKSucesso na ConsultaSua requisição GET foi processada e os dados foram retornados em JSON.
201 CreatedRegistro CriadoSua requisição POST cadastrou uma nova venda ou lançamento financeiro com sucesso.
400 Bad RequestDados IncompletosFaltou algum campo obrigatório no JSON (ex: client_name ou contact).
401 UnauthorizedNão AutorizadoO Bearer Token não foi enviado no cabeçalho ou a chave digitada está incorreta.
